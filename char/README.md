# Hope Foundation Church Charity

A responsive donation website for Hope Foundation Church Charity with:

- Home, About, Projects, Donate, Dashboard, and Blog pages
- Secure-looking donation form and recurring donation options
- Share links for WhatsApp, Facebook, and email

## Deploy to GitHub Pages

1. Create a GitHub repository and upload these files.
2. In the repository, go to Settings > Pages.
3. Choose Deploy from a branch.
4. Select the main branch and the root folder `/`.
5. Save changes.

Once published, the site will be available at:

https://<your-github-username>.github.io/char/
